# 简历格式（简历 DSL）

本文件定义 `简历.md` 的写法。写或改简历前先读这里；完整范例见 [sample-resume.md](sample-resume.md)。

简历是一份有硬规则的 Markdown：

| 元素 | 写法 |
|------|------|
| 首模块 | `# self-intro`（必须是第一个 `#`），下用 `key: value` 放 name / role / gender / location / phone / email / avatar / links 等。多值字段（links、education）用缩进子项：<br>`links:`<br>`- 作品集: url`<br>`education:`<br>`- 学校: xxx`<br>`- 专业: xxx` |
| 模块 | `# 模块名`（出现顺序 = 简历模块顺序） |
| 简介 | 模块下纯文本段 |
| 标签 | 模块下「标签, 标签」单行（研究兴趣 / 方向） |
| 经历 | `## 机构 \| 角色/方向`（无 `\|` 则只有机构名） |
| 项目经历标题 | 二段式：`## 项目名 \| 身份`；带所属公司时用三段式：`## 项目名 \| 公司(简称) \| 身份`。三种版本都必须把「身份」放在渲染结构的中央，公司简称只作为左侧项目的辅助信息。**公司一律用简称**（如「字节跳动」），取自 `profile.md` 里项目所属机构的核心词。**对比：工作经历/实习的 `## 机构` 用工商全称**（如「北京字节跳动科技有限责任公司」） |
| 经历/项目日期 | `date: 2024.07 — 2025.03`（经历级用 experience.period；项目级用 project.period，没设则继承父经历） |
| 经历补充 | `meta: GPA 3.9/4.0 · 排名 1/60`（关键数字用 `**`） |
| 经历要点 | `- 成就（STAR + 量化）` |
| 技能 | `- 类别: 值`，值为**证据式能力短句**：每句 = **程度词 + 核心能力 + 一个具体动作/结果**（如「熟练掌握多智能体编排，能独立实现子 Agent 调度」）；条目间用「；」、行末用「。」、同程度并列用「、」，按程度从高到低排列。**一类别至多 3–4 条、每条 1–2 行**，避免一句堆多个能力或多个动作。写前先做**能力聚类**（需求分析+场景拆解+方案定义 → "问题定义与方案设计"；项目管理+跨团队沟通+推进上线 → "项目推进与落地"），不要按工作流程拆成六七个技能栏；**一个能力若近乎人人具备、已被项目经历证明、无法差异化或只是相邻能力的自然步骤，则不单独列**（避免能力清单化/Completeness Bias），其余下沉到项目 bullet 做证据。**括号克制（硬规则）**：整行至多一处轻量补充（如分数、版本号），单句超 40 字或出现 2 个括号必须拆句重写——写能力边界与业务价值，不写操作手册与纯名词堆砌。程度词可用同义变体（深入掌握/熟练掌握/熟练应用/具备…经验）避免行内重复，等级语义对齐四级判据（唯一源：运行中的 `profile.md` 能力段，模板见 [profile.md](profile.md)；精通慎用——写了会被往底层和源码追问）；程度词与技能名间距按中西文混排（技能名中文开头不加空格、拉丁/数字开头加一个空格）。类别须按专业领域拆分（如编程语言、框架、数据存储、工程化、业务/领域知识各独立一类），不能跨域混放。渲染为文本行（分类与描述同行顶格起、续行自然顶格；分类标题「分类：」或「【分类】」行内形式），不用标签/chip/进度条等图形化形式 |

`name:` 必填；`avatar:` 给照片相对路径；`links` 放可线上展示自己的链接，如个人博客、飞书文档、作品集等（key: value）。

## 格式易错点

- **残留 `{{占位符}}`**：组件模板占位符必须全替换。
- **`# self-intro` 必须是首个 `#`**，渲染成 Header 而非 SectionHead。
- **不要手动补 `data-stick="1"`**：主题模板自带可保留，导出分页由预览壳 CSS 处理。
- **联系方式按实际字段拼**：没有的字段连同分隔符一起删。
- **`avatar:` 有就 `<img>`**：没照片用 [icons.md](icons.md) 的占位 SVG。
- **整篇只用所选主题的组件**，不从别的主题借。
- **标题层级只用 `#`/`##`**。
- **旧简历含照片**：用 `extract_avatar.py` 抽出 `avatar.png` 放进简历目录，再写 `avatar: avatar.png`；抽不到就留空。

导出渲染的细节见 [export.md](export.md)；主题与组件见 [themes/theme-index.md](themes/theme-index.md)。
