# 求职招呼语（Boss 直聘等平台）

招呼语生成的方法论与输出规范，通用（任意岗位 / 行业）。触发时机与"定稿后输出 3–5 条"的规则在 SKILL.md。

## 目标：过 HR 的 5 秒关

HR 给一条招呼语 ≤ 5 秒、列表预览只看前 1 行（约 25 字）、主动沟通回复率仅 10–30%。所以一条招呼语必须：**钩子在前 25 字、对标具体 JD、带 1 个数字、绝不群发同款**。

## 写法

- **公式**：`问候 + 岗位意向 + JD 命中点（带 1 个量化数字）+ 请求沟通`
- **30–50 字**，钩子在前 25 字。
- **岗位名必须与 JD 一致**（JD 写「大模型应用开发」就别写「算法工程师」）。
- 从 JD 提 2–3 个硬关键词，从简历找能佐证的项目，只放重合度最高的 1–2 个。
- 数字：业务大数字优先；没有就用工程指标（调用量 / QPS / 准确率提升 / 延迟降低 / 节省工时 / 转化率 / star / 数据规模 / 覆盖人数）。

## 雷区（秒拒写法）

- 只发「你好 / 在吗 / 求职 / 在找工作」
- 用平台自带打招呼模板（「您好，我非常感兴趣……」）
- 大段简历粘贴进招呼语
- 群发同款、不针对岗位微调（HR 识别得出模板感）
- 含外链 / 微信 / 手机号（多数平台限流折叠，且违规）
- 错别字、职位名写错
- 第一句就谈薪资
- 过度卑微（「请给我一个机会」）或过度傲慢（「我 offer 很多」）

## 五种方向

生成 3–5 条，**默认必含 A、B**，其余按画像从 C/D/E 补。`【…】` 是需按用户信息替换的占位。

| 方向 | 适用 | 模板 |
|------|------|------|
| **A 务实匹配**（默认首选） | JD 明确、有直接匹配经验 | 您好，【身份】，【X 年】【领域】经验，做过【JD 关键词对应的项目】。对贵司【岗位名】岗位很匹配，期待进一步沟通。 |
| **B 成果数字**（强钩子） | JD 强调工程落地 / 性能 / 产出 | 您好，对贵司【岗位名】岗位感兴趣。【做过的事】，把【指标】从【A】提升到【B】。熟悉【JD 关键技能】，期待沟通。 |
| **C 诚意理解** | 心仪公司，做过功课 | 您好，关注贵司【具体产品 / 业务线】，对你们在【具体方向】的工作很感兴趣。我有【相关经验】，希望聊聊能怎么贡献。 |
| **D 提问思考** | 技术负责人 / Boss 直发的岗，且对业务有理解；JD 不熟慎用 | 您好，看到贵司【岗位名】提到【JD 某重点】。我做过【相关经历】，想了解贵司更看重【维度 A】还是【B】？方便的话聊下匹配度。 |
| **E 极简直给** | 批量投递、列表预览场景 | 【届别 / 经验】｜【最强标签】｜对贵司【岗位名】岗位很匹配，期待沟通。 |

## 输出模板（按此结构产出）

```
【A · 务实匹配｜JD 明确的岗位】
<招呼语正文，≤50 字，可直接复制>

【B · 成果数字｜强调工程落地的岗位】
<招呼语正文>

…（按画像补 C / D / E，共 3–5 条）

📌 沟通建议：<一句话，见下>
```

## 输出前自检（任一不过即改）

- [ ] ≤ 50 字，钩子在前 25 字
- [ ] 岗位名与 JD 完全一致
- [ ] 至少 1 个对标 JD 的匹配点，最好带 1 个数字
- [ ] 不含雷区（你好 / 在吗 / 模板 / 大段粘贴 / 外链 / 谈薪 / 错别字）
- [ ] 需用户替换的信息都用 `【】` 标出

## 沟通建议（附在招呼语后，一句话给用户）

- **发送时机**：工作日 9–11 / 14–16 点，**周二上午 10 点**最佳。
- **薪资留面试**：招呼语不提薪资，HR 主动问或电话面时再谈。
- **配简历长图发**：招呼语最好配导出阶段生成的简历长图（招聘平台聊天框可发图，首轮即可发；图片比 PDF 少一次点击，HR 可直接看完）。长图在导出流程产出，不在本文件。

## 画像微调（通用维度）

- **核心经验前置**：最强的那段经历（未必是最近的）放第一句；应届把实习 / 项目当正式经验打，转行把可迁移能力前置。
- **岗位名带方向后缀**：如「【岗位】（【差异化标签】，如"多智能体全栈" / "亿级订单" / "0-1 搭建"）」。
- **项目讲业务价值**：只放能说清价值的项目，避免「课程作业 / 调 API demo」。
- **地域 + 到岗**：加「人在【城市】/ 【时间】可到岗」，消除异地、到岗顾虑。
- **对标 JD 是第一原则**：同一份简历投不同公司，按各家 JD 换命中点，别一条话术群发。
