# 求职招呼语（Boss 直聘等平台）

招呼语生成的方法论与输出规范，通用（任意岗位 / 行业）。触发时机与输出规则的入口在 SKILL.md（定向投 3–5 条 / 海投按海投模式）。

## 心法：IM 聊天逻辑，不是邮件逻辑

Boss 直聘这类平台基于 IM（即时通讯）逻辑，招呼语的本质**不是自我介绍，而是广告文案**——唯一目的是在对方滑过屏幕的 0.5 秒内抓住眼球，促使对方点开微简历或回复。

- **邮件逻辑必死**：起承转合、长篇大论、全面展示——对方是拿手机在碎片时间看消息。
- **IM 逻辑**：短平快、抛诱饵、等咬钩。招呼语是**预告片，不是正片**：只负责让对方产生「值得点开简历」的判断，深度展示交给简历与面试（简历长图/PDF 默认同发，不进正文）。
- **字数红线 150 字**：定向投 60–90 字最佳；海投 100–150 字。超过必须删套话，不删证据。
- **强制分段**：每 1–2 句换行，绝不允许密密麻麻一大段——手机上一屏能看完最好。
- **不使用 Emoji**：视觉锚点靠分段与数字呈现，不用 Emoji（与平台沟通场景的正式感不符）。

## 四模块构建框架

及格的招呼语说「我匹配」，优秀的招呼语说「我匹配且我有你无法拒绝的亮点」。四模块按序拼装：

### 模块一：注意力捕获（Attention Hook）——我是谁，我为什么找你

- **构建逻辑**：`[核心身份标签] + [求职意向 / 对岗位的理解]`，占前 25–30 字（列表预览只显示这一行）。
- **去学生气 / 去低级感**：不说「我是应届生 / 1 年经验」，亮身份标签——「AI 应用开发」「Agent 架构」「数据分析」。年限放句中弱化。
- **直击痛点**：JD 强调「大模型落地」，第一句就带「大模型落地」；强调「智能客服」，就带「智能客服」。

### 模块二：靶向匹配（Target Matching）——我为什么适合这个 JD

- **构建逻辑**：`[提取 JD 核心关键词] + [用核心经历做镜像回应]`。
- **找最大公约数**：JD 写了 10 个要求，只挑最核心、你最牛的 1–2 个回应——证明认真看过 JD，不是海投。
- **用动词 + 数据 / 结果**：不说「熟悉 Agent」，说「独立实现过 ReAct 主循环」「落地过上下文自压缩」。

### 模块三：降维打击 / 差异化（The Edge）——我为什么比别人强

**最核心的模块**：背景相似时，这个模块决定对方点开谁的简历。抛一个对方很难拒绝的钩子。

- **构建逻辑**：`[独家优势 / 底层探究精神 / 业务 Sense] + [带来的超预期价值]`。
- **三类钩子**：
  - **技术极客钩子**：深读源码并复刻内核、Agent 状态机设计、OOM 排查——秒杀只懂调包的候选人。
  - **业务 / 成本钩子**：KV Cache 显存精准测算、单条处理成本核算——击中技术总监 / 老板（他们最关心算力成本）。
  - **全栈闭环钩子**：2 天完成 20+ 微服务迁移、端到端独立交付——证明不是只会写算法，工程落地也能扛。

### 模块四：行动呼吁（Call to Action）——下一步干什么

- **构建逻辑**：`[不卑不亢的引导语] + [附件 / 微简历提示]`。
- **切忌乞讨**：不说「希望能给个面试机会」「求回复」。企业是来买生产力的，不是来办学校的。
- **自信平视**：「期待您的评估」「欢迎查阅附件简历了解技术细节」「随时方便深入交流」。

## 按对方身份调模块权重（动态策略）

发消息前先判断对方身份（JD 发布者头衔 / 公司规模），模块二、三的侧重点随之调整：

| 场景 | 对方 | 策略 |
|------|------|------|
| **A 技术 Leader / 总监 / CTO** | 懂技术，讨厌废话 | 弱化模块一，强化**模块三技术深度**：直接抛 Rust 复刻、Agent 状态机、Trade-off、底层原理等技术对话 |
| **B HR / 招聘专员 / 猎头** | 不懂底层，只看关键词 / 学历 / 稳定性 / 薪资匹配 | 强化**模块二关键词匹配**：JD 的词（LangGraph、RAG、K8s、Go）原样嵌进句子；弱化看不懂的技术，强调「全栈交付」「项目管理」「20+ 微服务迁移」这类好懂的业绩 |
| **C 初创 CEO / 业务负责人** | 关心能不能干活、省钱、快速出产品 | 强化**模块三业务与成本 Sense**：显存测算、单条处理成本、端到端独立交付、Vibe Coding 提效——招你一人能顶一个团队 |

## 写法：实操口吻，拒抽象框架词

每个分句用**具体动作 / 可证能力 / 数字**，不用**抽象能力框架词**。后者（如「把业务翻译成方案」「闭环」「跨职能交付推进」「赋能」「抓手」）在简历里成立，塞进百来字的招呼语就退化成 JD 复述——HR 读到的是「岗位能力模型」，不是「这个人做过什么」。

判断标准：写完每句问「这是具体动作 / 可证能力，还是能力标签？」是能力标签，就换成能证明它的具体动作，或删掉。以产品岗为例：

- ❌ 空：掌握跨职能交付、业务翻译、闭环能力，对岗位很匹配。
- ✅ 实：负责过芯片产业智能平台的产品化——主导 OCR 多模型选型、Agent 采集覆盖 557+ 厂商约 600 万条，把营销 Agent 回复速度从 60s 提到 20s。

## 死穴与雷区（秒拒写法）

**三个死穴**：

1. **查户口式提问**：「这个岗位还招人吗？」「薪资范围是多少？」——没看简历前问这些，直接拉黑。
2. **过度谦卑**：「我虽然经验不足，但我愿意学…」——企业买的是生产力，不是办学校；用项目数据证明能干活，不表决心。
3. **长篇自我介绍**：把简历里的个人简介复制进聊天框——没人看 300 字小作文。

**雷区**：

- 第一句只发「你好 / 在吗 / 求职」，或自我介绍占满钩子窗口、最强结果在 30 字之后
- 用平台自带打招呼模板（「您好，我非常感兴趣……」）
- 学生气开头（「我是应届生 / 我 1 年经验……」作第一词）
- 技能标签堆砌（5+ 个）或写项目证明不了的能力
- 抽象能力框架词（翻译/闭环/赋能/抓手）代替具体动作
- 群发同款、不按对方身份微调（HR 识别得出模板感）
- 含外链 / 微信 / 手机号（限流折叠且违规）、错别字、职位名写错、首句谈薪资

## 五种方向（定向投）

生成 3–5 条，**默认必含 A、B**，其余按画像从 C/D/E 补；再按「对方身份」调模块权重。`【…】` 是需按用户信息替换的占位。

| 方向 | 适用 | 模板 |
|------|------|------|
| **A 务实匹配**（默认首选） | JD 明确、有直接匹配经验 | 【身份标签】，做过【JD 关键词对应的项目，带结果】。对贵司【岗位名】很匹配，欢迎查阅附件简历。 |
| **B 成果数字**（强钩子） | JD 强调工程落地 / 性能 / 产出 | 【身份标签】。【做过的事】，把【指标】从【A】提升到【B】。熟悉【JD 关键技能】，期待您的评估。 |
| **C 诚意理解** | 心仪公司，做过功课 | 关注贵司【具体产品 / 业务线】，对你们在【具体方向】的工作很感兴趣。我有【相关经验】，希望聊聊能怎么贡献。 |
| **D 提问思考** | 技术负责人 / Boss 直发的岗，且对业务有理解；JD 不熟慎用 | 看到贵司【岗位名】提到【JD 某重点】。我做过【相关经历】，想了解贵司更看重【维度 A】还是【B】？方便的话聊下匹配度。 |
| **E 极简直给** | 批量投递、列表预览场景 | 【身份标签】｜【最强结果】｜贵司【岗位名】很匹配，期待您的评估。 |

## 海投模式（大量投递、JD 各异）

定向投对「某家 JD」，海投对「**岗位类别**」——不逐家定制，但避免被识别为群发：

- **钩子用类别级身份 + 通用结果**：只放这个岗位类别都认的信号，不用具体公司 / 产品名。只投类别对口的岗，JD 明显不匹配的别硬投（浪费沟通额度，还容易被标记）。
- **正文放该类别 JD 的共性技能**：翻 10 家同类 JD，重复出现的关键词才写（定向时从单家 JD 提 2–3 个硬关键词）；只有个别 JD 提的不写。
- **2–3 版轮换**：同一套证据换开头角度（结果 / 身份 / 极简），按周轮换，别几百家发同一句。
- **10% 微调阈值**：默认发万能款；某家 JD 明显偏一个方向时（如「智能客服」「数据采集」「国产大模型部署」），只换第二句对应证据，其余不动。
- **人在城市 / 到岗时间**放收尾前，消除异地、到岗顾虑。

## 输出模板

### 定向投（3–5 条，含 A、B，按画像补 C/D/E，标注对方身份场景）

```
【A · 务实匹配｜面向 HR（场景 B）】
<招呼语正文，60–90 字，分段，可直接复制>

【B · 成果数字｜面向技术 Leader（场景 A）】
<招呼语正文>

…（按画像补 C / D / E，共 3–5 条）

📌 沟通建议：<一句话，见下>
```

### 海投（1 条万能款 + 2–3 版轮换；100–150 字、强制分段）

以 AI Agent 应用开发为例（换成本人领域 / 岗位类别；数字必须来自真实项目）：

```
AI Agent 应用开发，深读过 Claude Code 源码、以 Rust 复刻过 Agent 内核。

做过 AI 营销 SaaS 与芯片产业智能平台的 Agent 引擎：ReAct 主循环、MCP 工具开发、多智能体编排，爬虫 Agent 采集多源数据近 600 万条。

Go/Python/TS 全栈落地，独立完成项目部署上线。方便的话，想和您聊聊匹配度！
```

要点：身份标签开头（不写「1 年经验」）、三段分明、Edge（复刻内核）独立成段、150 字内。轮换版按周换开头角度，其余不动。

## 输出前自检（任一不过即改）

- [ ] 钩子（前 25–30 字）= 身份标签 + 结果 / 匹配信号，无学生气开头、无套话
- [ ] 定向投：岗位名与 JD 完全一致；海投：岗位类别一致
- [ ] 靶向匹配：至少 1 个 JD 核心关键词被经历镜像回应，且带动词 + 数据
- [ ] Edge 模块：有一条对方难拒绝的差异化钩子（按对方身份选技术 / 业务 / 成本型）
- [ ] 字数 ≤150（定向 60–90 更佳）；已分段（每 1–2 句换行）
- [ ] 无三死穴：查户口、过度谦卑、长篇自我介绍
- [ ] 无抽象能力框架词（翻译/闭环/赋能等）；技能标签 ≤4 个且被项目证明
- [ ] 收尾自信平视；无卑微 / 谈薪 / 外链 / 错别字；全文无 Emoji
- [ ] 简历长图/PDF 已准备好同发（默认动作，不进正文）
- [ ] 需用户替换的信息用 `【】` 标出（海投示例按本人信息改）

## 沟通建议（附在招呼语后，一句话给用户）

- **发送时机**：工作日 9–11 / 14–16 点，**周二上午 10 点**最佳（也有招聘方认为时机影响不大，看到合适岗位尽快投更重要）。
- **薪资留面试**：招呼语不提薪资，HR 主动问或电话面时再谈。
- **配简历长图发**：必须与招呼语同时发出（平台聊天框可发图，首轮即可看完整简历；图片比 PDF 少一次点击）。长图在导出流程产出；不写进招呼语正文。
- **海投节奏**：2–3 版按周轮换；某家 JD 明显偏方向时只换第二句。

## 画像微调（通用维度）

- **核心经验前置**：最强的那段经历（未必是最近的）放第一句；应届把实习 / 项目当正式经验打，转行把可迁移能力前置——但钩子仍用身份标签，不用「应届 / X 年经验」开头。
- **岗位名带方向后缀**：如「【岗位】（【差异化标签】，如"多智能体全栈" / "亿级订单" / "0-1 搭建"）」。
- **项目讲业务价值**：只放能说清价值的项目，避免「课程作业 / 调 API demo」。
- **地域 + 到岗**：加「人在【城市】/ 【时间】可到岗」，消除异地、到岗顾虑。
- **对标 JD 是第一原则**：定向投按各家 JD 换命中点；海投按岗位类别维护万能款 + 10% 微调。
