# 求职招呼语（Boss 直聘等平台）

招呼语生成的方法论与输出规范，通用（任意岗位 / 行业）。触发时机与输出规则的入口在 SKILL.md（定向投 3–5 条 / 海投按海投模式）。

## 目标：让 HR 愿意点开简历

HR 一天看几百条招呼语，列表预览只看第一行（约 25–30 字）；Boss 直聘等平台**查看每份简历都需要付费**。所以招呼语是**预告片，不是正片**：只负责让 HR 产生「这个人值得点开简历」的判断，详细证据交给简历（招呼语与简历长图/PDF 同时发出）。

- **钩子窗口**：前 25–30 字决定 HR 是否点开。第一句 = 身份 + 最强结果 / 信号，套话（「对贵司岗位很感兴趣」）不进钩子。**25 字是钩子窗口，不是总长上限。**
- **总长按场景**：定向投 60–90 字；海投（大量投、JD 各异）可 140–180 字。判断标准是「无冗余」——删套话与无关内容，不压缩证据。
- **简历长图/PDF 默认同发**：平台聊天框可发图，首轮即可看完整简历。这是默认动作，**不写进招呼语正文**。

## 结构：四段式

`身份 + 结果钩子 → 项目证据（做了什么 + 数字） → 技能标签（2–4 个对齐 JD） → 自信收尾`

1. **身份 + 结果钩子（前 25–30 字）**：一句话给「我是谁 + 我做出过什么」。结果优先业务数字（响应时间 / 转化 / 数据量），没有就用工程指标（调用量 / QPS / 延迟 / 节省工时 / star / 覆盖人数）。以 AI Agent 应用开发为例：「1年AI应用开发经验，营销Agent客户首响60s→7s」。
2. **项目证据**：1–2 个与岗位最相关的项目，每个带 1 个量化结果；只放能说清业务价值的项目，不放课程作业 / demo。
3. **技能标签**：2–4 个对齐 JD 的硬关键词（JD 里出现、且项目能证明的）；差异化标签（JD 没有但显深度的）至多 1 个放末尾。别把简历技能区全搬进来——超过 5 个就稀释重点、像背书；工具名不作为标签（「用过」不是「会」）。
4. **自信收尾**：轻量邀请或一个可回答的问题（「方便的话，想和您聊聊匹配度？」），比「期待您的回复」更易换来回复。不卑微（「请给我一个机会」）、不谈薪。

## 写法：实操口吻，拒抽象框架词

每个分句用**具体动作 / 可证能力 / 数字**，不用**抽象能力框架词**。后者（如「把业务翻译成方案」「闭环」「跨职能交付推进」「赋能」「抓手」）在简历里成立，塞进百来字的招呼语就退化成 JD 复述——HR 读到的是「岗位能力模型」，不是「这个人做过什么」，显得空洞、像套话。

判断标准：写完每句问「这是具体动作 / 可证能力，还是能力标签？」是能力标签，就换成能证明它的具体动作，或删掉。区别在于**「我做过 / 我能扛」的实物感**，不是「我很匹配」的求职腔。

以产品岗为例：
- ❌ 空：掌握跨职能交付、业务翻译、闭环能力，对岗位很匹配。
- ✅ 实：负责过芯片产业智能平台的产品化——主导 OCR 多模型选型、Agent 采集覆盖 557+ 厂商约 600 万条，把营销 Agent 回复速度从 60s 提到 20s。

## 雷区（秒拒写法）

- 第一句只发「你好 / 在吗 / 求职」或自我介绍占满钩子窗口，最强结果在 30 字之后
- 用平台自带打招呼模板（「您好，我非常感兴趣……」）
- 大段简历粘贴进招呼语（招呼语是预告片，不是简历全文）
- 技能标签堆砌（5+ 个）或写了项目证明不了的能力
- 用抽象能力框架词（翻译/闭环/赋能/抓手）代替具体动作——读起来像 JD 复述，空洞
- 群发同款、不针对岗位类别微调（HR 识别得出模板感）
- 含外链 / 微信 / 手机号（多数平台限流折叠，且违规）
- 错别字、职位名写错
- 第一句就谈薪资
- 过度卑微（「请给我一个机会」「非常期待能有机会与您进一步沟通」）或过度傲慢（「我 offer 很多」）

## 海投模式（大量投递、JD 各异）

定向投对「某家 JD」，海投对「**岗位类别**」——不逐家定制，但避免被识别为群发：

- **钩子用类别级身份 + 通用结果**：只放这个岗位类别都认的信号，不用具体公司 / 产品名。只投类别对口的岗，JD 明显不匹配的别硬投（浪费沟通额度，还容易被标记）。
- **正文放该类别 JD 的共性技能**：翻 10 家同类 JD，重复出现的关键词才写（定向时从单家 JD 提 2–3 个硬关键词）；只有个别 JD 提的不写。
- **2–3 版轮换**：同一套证据换开头角度（结果 / 身份 / 极简），按周轮换，别几百家发同一句。
- **10% 微调阈值**：默认发万能款；某家 JD 明显偏一个方向时（如「智能客服」「数据采集」「国产大模型部署」），只换第二句对应证据，其余不动。
- **人在城市 / 到岗时间**放收尾前，消除异地、到岗顾虑。

## 五种方向（定向投）

生成 3–5 条，**默认必含 A、B**，其余按画像从 C/D/E 补。`【…】` 是需按用户信息替换的占位。

| 方向 | 适用 | 模板 |
|------|------|------|
| **A 务实匹配**（默认首选） | JD 明确、有直接匹配经验 | 您好，【身份】，【X 年】【领域】经验，做过【JD 关键词对应的项目】。对贵司【岗位名】岗位很匹配，期待进一步沟通。 |
| **B 成果数字**（强钩子） | JD 强调工程落地 / 性能 / 产出 | 您好，对贵司【岗位名】岗位感兴趣。【做过的事】，把【指标】从【A】提升到【B】。熟悉【JD 关键技能】，期待沟通。 |
| **C 诚意理解** | 心仪公司，做过功课 | 您好，关注贵司【具体产品 / 业务线】，对你们在【具体方向】的工作很感兴趣。我有【相关经验】，希望聊聊能怎么贡献。 |
| **D 提问思考** | 技术负责人 / Boss 直发的岗，且对业务有理解；JD 不熟慎用 | 您好，看到贵司【岗位名】提到【JD 某重点】。我做过【相关经历】，想了解贵司更看重【维度 A】还是【B】？方便的话聊下匹配度。 |
| **E 极简直给** | 批量投递、列表预览场景 | 【届别 / 经验】｜【最强标签】｜对贵司【岗位名】岗位很匹配，期待沟通。 |

## 输出模板

### 定向投（3–5 条，含 A、B，按画像补 C/D/E）

```
【A · 务实匹配｜JD 明确的岗位】
<招呼语正文，60–90 字，可直接复制>

【B · 成果数字｜强调工程落地的岗位】
<招呼语正文>

…（按画像补 C / D / E，共 3–5 条）

📌 沟通建议：<一句话，见下>
```

### 海投（1 条万能款 + 2–3 版轮换）

以 AI Agent 应用开发为例（换成本人领域 / 岗位类别；数字必须来自真实项目）：

```
您好！我有1年AI Agent应用开发经验。负责过AI营销SaaS与芯片产业智能平台的Agent引擎：具有AI Native思维，Agent开发、多Agent编排、工具开发，做过爬虫Agent得到多源采集数据近600万条。掌握Agent Loop、ReAct、上下文管理，熟悉RAG/向量检索，能Go/Python/TS等各类语言全栈落地，且能独立交付项目部署上线。方便的话，想和您聊聊匹配度！
```

轮换版：把最强数字提前到首句（严格钩子前置），如「您好！1年AI Agent应用开发经验，爬虫Agent多源采集近600万条。……」；其余正文不动。按周在 2–3 版间轮换。

## 输出前自检（任一不过即改）

- [ ] 钩子（前 25–30 字）含身份 + 至少 1 个结果 / 匹配信号
- [ ] 定向投：岗位名与 JD 完全一致；海投：岗位类别一致
- [ ] 至少 1 个量化数字，能对标 JD 更好
- [ ] 技能标签 2–4 个、对齐 JD、且被项目证明；无 5+ 标签堆砌
- [ ] 无抽象能力框架词：每句是具体动作 / 可证能力 / 数字，不是能力标签（翻译/闭环/赋能等）
- [ ] 收尾自信、可回答；无卑微 / 谈薪 / 外链 / 错别字
- [ ] 简历长图/PDF 已准备好同发（默认动作，不进正文）
- [ ] 需用户替换的信息用 `【】` 标出（海投示例按本人信息改）

## 沟通建议（附在招呼语后，一句话给用户）

- **发送时机**：工作日 9–11 / 14–16 点，**周二上午 10 点**最佳（也有招聘方认为时机影响不大，看到合适岗位尽快投更重要）。
- **薪资留面试**：招呼语不提薪资，HR 主动问或电话面时再谈。
- **配简历长图发**：默认与招呼语同时发出（平台聊天框可发图，首轮即可看；图片比 PDF 少一次点击）。长图在导出流程产出，不在本文件；**不写进招呼语正文**。
- **海投节奏**：2–3 版按周轮换；某家 JD 明显偏方向时只换第二句。

## 画像微调（通用维度）

- **核心经验前置**：最强的那段经历（未必是最近的）放第一句；应届把实习 / 项目当正式经验打，转行把可迁移能力前置。
- **岗位名带方向后缀**：如「【岗位】（【差异化标签】，如"多智能体全栈" / "亿级订单" / "0-1 搭建"）」。
- **项目讲业务价值**：只放能说清价值的项目，避免「课程作业 / 调 API demo」。
- **地域 + 到岗**：加「人在【城市】/ 【时间】可到岗」，消除异地、到岗顾虑。
- **对标 JD 是第一原则**：定向投按各家 JD 换命中点；海投按岗位类别维护万能款 + 10% 微调。
