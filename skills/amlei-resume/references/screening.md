# 招聘方如何筛选简历

> 用途：帮助模型在选材和组织之前，先判断目标岗位的第一轮筛选字段，而不是默认从 `self-intro` 或“开头几行”开始。
>
> 这不是一份必须逐条打勾的规则表；招聘方、岗位、地区和 ATS 不同，优先级会变化。

## 核心结论

- 简历不是文章，筛选者不是读者。筛选者带着岗位标准主动查找证据、快速排除。
- 第一轮是 initial skim（初筛），不是完整阅读；通过初筛后才会进入更长时间的阅读。
- TheLadders 2012 eye-tracking 研究发现，初扫约 80% 注意力集中在六个字段：姓名、当前职位、当前公司、当前任职时间、上一段职位、教育。2018 年更新把平均初扫时间从约 6 秒修正为约 7.4 秒。
- 页面上三分之一、左侧和每段经历的前两条 bullet 更容易被看到。
- ATS 先做结构和关键词解析，人工初筛在其后；可读的视觉结构通常也有利于 ATS，但 ATS 不懂“叙事”。

来源：

- Careerflow, *The Myth of the “6 Second Rule” on Resumes*: <https://www.careerflow.ai/blog/6-second-rule-resume>
- TheLadders 2012 eye-tracking study: <https://www.theladders.com/static/images/basicSite/pdfs/TheLadders-EyeTracking-StudyC2.pdf>

这些研究是默认启发式，不是所有岗位、地区和招聘流程的定律。岗位、资历、行业和 ATS 会改变第一轮字段的优先级。

## 第一轮筛选字段

先根据目标岗位、JD、资历和行业，判断筛选者第一轮会找什么。常见字段包括：

- 目标/当前职位、当前公司、任职时间；
- 上一段相关职位；
- 教育、证书或专业训练（尤其应届、转行、技术/资质型岗位）；
- 最强相关证据（结果、规模、作品、可验证链接）；
- ATS 关键词（技能、工具、领域词）；
- 风险信号（时间断层、角色越界、证据不可核验）。

这些字段不一定都在同一个模块：

- `self-intro`：身份、目标职位、教育、链接；
- `个人简介`：定位与主线；
- `工作经历`：当前/上一段公司、职位、时间、职责与结果；
- `项目经历`：最强项目证据与可追问细节；
- `专业技能`：ATS 关键词与能力摘要；
- 教育/证书：按资历和岗位决定是否靠前。

不要默认 `self-intro` 就是筛选入口，也不要把同一个字段在每个模块重复一遍。

## 按候选阶段调整

- 应届 / 早期候选人：教育、专业、项目/实习和最强作品可能更重要；教育可以靠前。
- 有 3 年以上相关经验：当前/最近职位、公司、时间和最近成果优先；教育通常可以后移。
- 转行 / 跨领域：目标职位、可迁移能力、项目证据和训练/证书优先；不要只靠自我评价。
- 技术 / 工程岗位：当前技术栈、项目规模、系统边界和可核验结果优先；工具名要出现在证据语境里。
- 产品 / 业务岗位：业务对象、角色、决策、指标、交付结果和跨职能范围优先。

## 写作含义

- 当前职位、公司、时间、上一段 title、教育/证书和 ATS 关键词要容易找到。
- 每段经历的前两条 bullet 放最强证据；每个项目第一条放最强结果。
- 专业技能是 ATS/关键词支持，不承担主要筛选叙事；能力证据优先放在工作和项目 bullet。
- 个人简介负责定位，不替代当前职位/公司/时间和最强证据。
- 页面结构、主题和字号会影响视觉位置，但页数以渲染脚本为准；不要用“第一屏”或“开头几行”猜。

## 自检问题

1. 目标岗位的第一轮筛选字段是什么？它们是否都能被快速找到？
2. 当前/最近职位、公司、时间、上一段相关职位、教育/证书是否清楚？
3. 最强证据是否出现在每段经历的前两条 bullet 和每个项目的第一条？
4. ATS 关键词是否覆盖岗位要求，且没有堆砌？
5. 是否有无法核验、角色越界、时态不清或重复的证据？
