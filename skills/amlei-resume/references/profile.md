# 记忆底座模板（profile.md）

`profile.md` 是跨会话认识用户的画像。每次开聊先读它，AI 就能直接进入"针对这个方向怎么组织"，而不是从零问起。原始素材、长文与逐条证据放 `materials/`，这里只保留确认后的短事实。使用策略见 SKILL.md 的「记忆与材料」；本文件只放模板和熟练度判据。

`profile.md` 只放跨方向稳定的信息。目标岗位、行业/公司、层级、城市、目标公司和 JD 基准属于 `identities/{identity-id}/target.json`；调研证据属于同方向的 `research/`。现有文件不要求机械迁移成固定段数，但应逐步移出只属于某个方向的目标设定。

可以在末尾加一条可选的 `## 材料索引` 指针，只写 `materials/index.md`，不把素材正文搬进 `profile.md`。

## 文件模板

```markdown
# 关于我
- 姓名 / 城市 / 联系方式 / 教育 / 链接

# 经历与项目
## 机构 | 角色 | 时间
- 做过什么，结果如何（带数字/证据）

## 项目名 | 角色 | 时间
- 关键决策与结果

# 能力与证据
- 能力：由哪个项目/成果证明（熟练度用 精通/熟练/熟悉/了解）

# 跨方向偏好
- 长期方向 / 明确排除：
- 工作方式 / 地域等稳定偏好：
- 通用表达偏好：

# 待确认
- 下次要问的缺口、待核实数字
```

## 熟练度四档

`精通`（深入理解底层、能解决疑难、有架构设计或造轮子能力，**慎用**——写了会被往底层和源码追问）、`熟练`（日常主力、能独立高效交付复杂业务）、`熟悉`（项目用过、能完成日常开发）、`了解`（知道概念/Demo 级）。证据不足时就低不就高。
